# My Menu (`ben.menu`)

An Omarchy shell plugin for the status bar menu with an authentic, high-resolution Quake II emblem.

## Features
- Launches the native Quickshell-powered Omarchy command menu on left-click.
- Launches default terminal on right-click.
- Features the authentic textured Quake II logo asset.

## Installation
```bash
omarchy plugin add https://github.com/bchurch95/omarchy-menu.git
omarchy plugin enable ben.menu
```
